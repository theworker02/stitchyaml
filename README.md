# stitchyaml

Stitch lightweight yaml statistics from stdin samples.

**Site:** https://theworker02.github.io/stitchyaml/

## Install / run

```bash
git clone https://github.com/theworker02/stitchyaml.git
cd stitchyaml
node src/cli.js
node --test
```
